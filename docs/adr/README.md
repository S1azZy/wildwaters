# ADRs

Small architecture decision records for durable, cross-cutting choices.
Feature intent, acceptance behavior, design exploration, and implementation
tasks belong in OpenSpec. Create an ADR only when a confirmed Level 3 change
introduces a decision that should outlive the feature change.
